The USID reader and writer no longer depend on ``pyUSID`` and ``sidpy``: h5USID files are read and written directly with ``h5py``, which adds support for numpy 2. The ``pyUSID_version`` item is no longer added to the ``original_metadata``, the attributes of the ``Measurement`` group are now included in ``original_metadata.parameters``, and metadata that cannot be written as HDF5 attributes is reported with a warning instead of being skipped silently.
