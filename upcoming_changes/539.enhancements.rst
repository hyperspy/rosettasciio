:ref:`zspy-format`: support zarr 3 in addition to zarr 2, and widen the ``zspy`` dependency to ``zarr>=2,<4``. Saving ragged arrays (such as variable-length markers or diffraction vectors) is not supported with zarr 3 yet and raises an explanatory error; reading a file whose ragged arrays were written with zarr 2 also raises an explanatory error under zarr 3. Install ``zarr<3`` for those cases.
